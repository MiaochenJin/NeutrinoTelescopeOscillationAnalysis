# NeutrinoTelescopeOscillationAnalysis

Running analysis:
Analysis and plotting scripts are located in ./scripts. 
For setting up analysis best fit points and turn on/off systematics sources, yaml config files are located in ./config
Some necessary data including MC files as well as binning information are in ./datafiles
Lastly, ./script/plot_sensitivity.py will automatically save to ./results. Read the argument parser defined within the file for more detail.
